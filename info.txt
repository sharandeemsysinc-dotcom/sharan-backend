
Run Commands:

<--- Installation Steps -->
npm install // for installing all dependencies.
npx prisma generate // run this cmd after npm install.
npx prisma db push // run this cmd for pushing schema changes without migration.
npx prisma db seed // run this command for seeded data. 
npm run dev // for running the server.

<--- " Additional Commands " --->
npx prisma format // run this cmd for formatting prisma schema.
npm run merge:prisma // for new or add any model changes run this.
npx prisma migrate reset // drop your db. 
npm run test (or)  npx vitest run // run your test cases.
npx prisma studio // run this cmd for browser db.
